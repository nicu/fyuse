# fyuse

A video scrubber that lets you scrub through a video by moving your mouse across the frames.

## Live demo

👉 [https://nicu.github.io/fyuse/](https://nicu.github.io/fyuse/)

## How it works

- `index.html` — page shell
- `app.js` — samples frames from `movie.mov` into a canvas and lets you scrub by mouse position
- `.github/workflows/deploy.yml` — deploys to GitHub Pages on push to `main`
